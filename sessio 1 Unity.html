DIAPOSITIVA 1

Els Motors de Videojocs (Game Engines)

Què és un Motor de Videojocs? És un conjunt d'eines i llibreries de programari dissenyades per simplificar, accelerar i optimitzar la creació i desenvolupament de videojocs.

Funcionalitats Clau:

  • Motor de Renderitzat: Dibuixa gràfics 2D/3D a la pantalla en temps real.
  • Motor de Física: Simula col·lisions, gravetat, fricció i velocitats.
  • Gestió d'Àudio i Entrada: Processa sons, música i perifèrics (teclat, ratolí, gamepad).
  • Multiplataforma: Permet exportar el mateix projecte a PC, consoles, mòbils i web.
💡 Nota destacada: Sense un motor, caldria programar des de zero l'accés a la targeta gràfica, la física matemàtica i el sistema d'arxius per a cada joc.
DIAPOSITIVA 2

Unity 3D com a Eina del Curs

Per què utilitzem Unity? Estàndard absolut de la indústria indie i professional. Ofereix un entorn integrat excel·lent per a 2D i 3D amb una comunitat gegant.

Unity Hub & Descàrrega

Usem Unity Hub per gestionar versions de l'editor i projectes. Web oficial: unity.com

Versió LTS (Long Term Support)

Versions amb suport a llarg termini (2-3 anys de parches i correccions). Garanteix màxima estabilitat durant el curs sense canvis bruscos en l'API.

Documentació Oficial

Manual de Unity (explicació d'eines i interfície) i Scripting Reference (documentació exhaustiva de totes les classes i mètodes de C#).

DIAPOSITIVA 3

Programació Orientada a Objectes (OOP) i C#

El Paradigma OOP: Model de programació basat en Classes (plantilles o motlles) i Objectes (instàncies reals d'aquestes classes).

Els 4 Pilars de la POO:

  1. Encapsulació: Protegir i organitzar les dades internes.
  2. Herència: Permet crear noves classes basades en existents (ex: ScrPlayer : MonoBehaviour).
  3. Polimorfisme: Capacitat d'utilitzar mètodes amb el mateix nom però diferent comportament.
  4. Abstracció: Ocultar la complexitat interna i mostrar només el necessari.
public class ScrPlayer : MonoBehaviour {
  // La majoria de scripts a Unity hereten de MonoBehaviour
}
DIAPOSITIVA 4

Generant el Meu Primer Projecte 2D

Passos a Unity Hub:

  1. Obrir Unity Hub.
  2. Fer clic al botó New Project.
  3. Seleccionar la versió instal·lada de Unity LTS.
  4. Escollir la plantilla: 2D (Core) o 2D (URP).

Configuració del Projecte:

  • Project Name: SpaceShooter_2D (noms clars sense espais ni caràcters especials).
  • Location: Ruta local al disc dur (evitar OneDrive/Dropbox per prevenir bloquejos de fitxers).
DIAPOSITIVA 5

Estructura en Disc del Projecte Generat

Quan Unity crea un projecte, genera les següents carpetes al teu disc:

Assets/

LA CARPETA MÉS IMPORTANT. Conté tots els sprites, codi, àudio i escenes. És l'única que cal incloure obligatòriament a Git.

ProjectSettings/ — Configuracions del projecte (teclat, capes, gràfics). Incloure a backups.
Library/ , UserSettings/ , Temp/ — Fitxers de cache i temporals. NO pujar a Git!
Fitxers .meta: Arxius d'identificació única (GUID) de cada recurs. Mai s'han d'esborrar manualment.
DIAPOSITIVA 6

La Interfície de Unity

Les 5 Finestres Principals de l'Editor:

1. Hierarchy (Jerarquia): Mostra tots els GameObjects presents a l'escena activa en forma d'arbre.
2. Scene View (Vista d'Escena): Espai de treball visual 2D/3D on col·loquem i manipulem objectes.
3. Game View (Vista de Joc): La visió de la càmera; mostra exactament el que veurà el jugador.
4. Project Window: Explorador de fitxers que mostra el contingut real de la carpeta Assets/.
5. Inspector: Mostra i permet editar les propietats i components de l'objecte seleccionat.

* Extra: Console mostra els missatges de depuració (Debug.Log()) i errors de codi.

DIAPOSITIVA 7

Conceptes Bàsics de Unity

GameObjects

L'entitat base de Unity. Per si sol és un contenidor buit que només té posició, rotació i escala (Transform).

Components

Mòduls de funcionalitats que s'afegeixen als GameObjects (ex: renderitzat, física, col·lisions).

Prefabs

Plantilles reutilitzables de GameObjects. Permeten instanciar múltiples còpies sincronitzades (ex: enemics, projectils).

Scripts

Components personalitzats en C# que defineixen el comportament i la lògica del joc.

DIAPOSITIVA 9

Importació i Sprite Editor

Importem la imatge Spritesheet spaceshooter.png a Assets/Sprites/.

Configuració a l'Inspector de la Imatge:

  • Texture Type: Sprite (2D and UI)
  • Sprite Mode: Multiple (conté múltiples sprites en una imatge).
  • Filter Mode: Point (no filter) per Pixel Art o Bilinear per gràfics suaves.

Ús de l'Sprite Editor:

  1. Clic al botó Sprite Editor a l'Inspector.
  2. Clic a Slice → Tipus: Automatic o Grid by Cell Size.
  3. Prem Apply per desar el retallat.
DIAPOSITIVA 10

Creació del Player i Estructura "Canó"

Configuració del Player:

1. Crear GameObject Player i assignar l'sprite de la nau.

2. Afegir component Rigidbody 2D → Gravity Scale = 0 (entorn d'espai sense gravetat).

3. Afegir Box Collider 2D per a col·lisions.

4. Crear el script ScrPlayer.cs a la carpeta _Scripts/.

Crear el GameObject Fill "Canó":

Clic dret sobre Player → Create Empty → Nom: Cano.

Posicionar-lo a la punta frontal de la nau per utilitzar-lo com a punt d'origen d'instanciació dels dires/projectils.
